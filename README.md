# 🛡️ AutoBattler - Projet POO (L1-S2)

![Bannière](./header.png)

## 🎮 Description

AutoBattler est un projet scolaire de POO en JAVA. Chaque combattant possède des caractéristiques (vie, vitesse, défense, capacité) et le combat progresse manche après manche jusqu’à la victoire d’une équipe.
